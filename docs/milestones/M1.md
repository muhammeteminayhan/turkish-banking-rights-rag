## Code review

Two reviews ran on the first version (`ecc:python-reviewer`, `ecc:security-reviewer`).
No CRITICAL findings. Everything rated HIGH or MEDIUM was fixed, test first:

| Finding | Fix |
|---|---|
| Redirects and the scraped iframe URL could reach any https host (SSRF) | Host allowlist + port check on every hop; iframe must be `/anasayfa/MevzuatFihristDetayIframe` on www.mevzuat.gov.tr |
| Unbounded response size / decompression | Streamed, `Accept-Encoding: identity`, 50 MB cap, 180 s deadline |
| robots.txt matched the token "Mozilla", not ours; `Crawl-delay` ignored; robots redirects not followed | `can_fetch("finhak", …)`, `Crawl-delay` raises the per-host interval, redirects followed |
| Page/text cached before validation; cache never re-checked | Validated before saving; cache hit needs same URL and same SHA-256 |
| A plain HTML error page passed as `doc_html` | Requires Word's `Generator` meta tag |
| Two links with the same extension silently collided | `ScrapeError` |
| NaN interval disabled the rate limit; `Retry-After: nan` crashed | `math.isfinite` guards |
| Uncaught `ValueError`/`JSONDecodeError`/`httpx.DecodingError` ended the run with a traceback | Typed errors (`ScrapeError`, `CorruptFetchLog`, `FetchError`); CLI exit codes 0/1/2 |
| Optional file 404 aborted the document; `--refresh` + bad response deleted a good copy | Reported in `failed`, other files continue; previous copy kept |
| Dry run did not match the real plan | Uses the same cache rule, honours `--refresh` and rejections |
| Tests whose names promised more than they checked | Rewritten with exact assertions |

Left for later, on purpose: a dependency lockfile and `pip-audit` (M6, with CI); robots.txt
wildcards (stdlib limitation, irrelevant for mevzuat.gov.tr today).

## Issues found and how they were handled

1. **Some `.doc` files are HTML.** First run: 4 documents failed the OLE2 magic check.
   Three of them (11180, 19798, 38873) are Word "web page" exports in UTF-16LE. They are now
   recognised and labelled `doc_html`.
2. **One `.doc` is corrupt on the server.** 39730's `.doc` is double-encoded (UTF-16LE →
   Windows-1254 → UTF-16LE). Optional Word/PDF files whose bytes do not match are now
   *rejected* instead of aborting the document: not saved, logged as a warning, recorded with
   the reason in `_fetch.json` and in `rejected_files` in the manifest. Page and text stay
   mandatory. 39730's HTML text and PDF are fine.
3. **Amendment notes have three spellings.** `RG-…`, `RG -…` (space) and a prefix-less
   `17/12/2010-27788` form. The first parser missed the last two (kart-yon count went from
   68 to 71 after the fix). All three are covered by tests.
4. **resmigazete.gov.tr answers Python's urllib with HTTP 400** (after a redirect) while curl
   works. Only relevant for Phase 2's Resmî Gazete tracker; noted, not investigated further.

## Decision: current fee amounts (2026-10-23)

The Tebliğ 2020/7 states its caps with their **original nominal amounts**; TCMB raises them
every year by the TÜİK CPI and publishes the current values only in its *Uygulama
Talimatı* (tcmb.gov.tr PDF, version dated 13.01.2026, e.g. the EFT cap table "from
6/1/2026"). Without it the assistant would quote outdated amounts, the exact problem the
project exists to fix.

Chosen: **option A**. The talimat is the 16th document (`tcmb-ucret-talimat`,
`origin: tcmb`):

- The fetcher reads its URL from the TCMB listing page by link text. It never hard-codes the
  URL, which changes with each version.
- The version date in the file name is checked against `expected_version_date`. A new
  version on the site makes the manifest build fail until `sources.yaml` is updated.
- Answers that cite it must show its version date (requirement for M4).
- Collection: 3 requests (robots.txt → 404, listing page, PDF of 216,213 bytes); rerun 0.
