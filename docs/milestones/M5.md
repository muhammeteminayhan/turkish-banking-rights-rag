## Method (from the approved plan, with what M4 added)

**Free only** (your decision, 2026-10-29): no paid API anywhere. Answers come from the local
Qwen3 8B. The judge is either a local open model through Ollama, or Gemini's free tier
with your key. The Anthropic provider stays in the code but is not used.

**Runs:**
- `python eval/smoke_ask.py --all` answers every golden question and saves the raw rows.
  The rows include the withheld drafts, which are never shown to the user.
- `python eval/judge.py <run> [--judge ollama|gemini] [--model …]` scores them:
  - Refusals, withheld answers and errors are scored by rule.
  - Every other answer goes to the judge, which compares it with the expected answer and
    its evidence quotes.
  - Each score is appended to `judgments.jsonl` as soon as it is made, so a run cut off by
    a daily quota continues where it stopped.
  - The rubric's version is stored with each score.
- A third command, `eval/report.py`, will build the final tables.

**Metrics:**
- retrieval: Recall@5/10 and MRR;
- citation precision and recall at article level;
- correct refusals of out-of-scope questions, and false refusals;
- false-premise correction rate;
- answer correctness (rubric-based LLM judge);
- latency p50/p95 and cost per question;
- bootstrap 95 % intervals on the main numbers.

**Your hand scores.** You score ~30 answers by hand, and I report the judge's agreement
with you (% and Cohen κ).

**What M4 adds:**
- **Refusal threshold:** measure the top reranker score as a refusal gate on the 25
  out-of-scope questions. In M4 the out-of-scope tops were 0.04–0.06 and the answerable
  ones at least 0.58.
- **Withheld drafts:** keep them in the raw rows for the error analysis (never shown).
- **Rubric checks:** the judge must check two errors the deterministic checks miss.
  - additions with no source behind them, like b1-060's "konut finansmanı hariç";
  - the wrong row or column of a table, like b1-033's 15,96 TL.

**Ablations:**
- the retrieval configurations;
- Qwen3 8B with thinking (the default) vs without;
- optionally, Gemini's free tier as the answering model (`LLM_PROVIDER=gemini`).
